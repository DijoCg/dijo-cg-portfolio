# Dijo C.G. — Portfolio

Responsive single-page developer portfolio built with React, Vite, Tailwind CSS, Framer Motion and GSAP ScrollTrigger.

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Add your profile photo

Place your portrait at `public/profile.jpg`. Recommended: portrait orientation, clear face, good lighting, 4:5 crop. The hero currently includes a designed placeholder and will display your image automatically once this file exists.

## Before publishing

- Review `src/data/content.js` and confirm all descriptions and contact details.
- Add your LinkedIn URL to `profile.linkedin` if you want it displayed.
- Replace `public/resume.pdf` with your latest CV.
- Verify that public project links and live demos still work.
- Resume projects without a confirmed URL are intentionally shown without fabricated links.
- The E-commerce Admin Dashboard is labeled private and shown as text only.

## Included from resume

Experience, skills, all four resume projects, all three education entries and all seven listed certifications.
